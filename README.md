# Qalam.

Умный переключатель раскладки для **Windows и macOS** с поддержкой **таджикского**, русского и английского. Похож на Punto Switcher, но знает таджикский язык и официальную таджикскую раскладку (ғ ӣ қ ӯ ҳ ҷ).

Сделано студией видеопродакшена медиагруппы «Азия-Плюс».

## Что умеет

- **Автоисправление.** Набрали `ghbdtn` — после пробела получится «привет», и раскладка переключится сама. Работает и для таджикского: `щамчун` → «ҳамчун», `создатӣ` → «создать».
- **Ручное исправление.** Горячая клавиша меняет раскладку текущего или только что набранного слова. Повторные нажатия перебирают EN → RU → TJ.
- **Отмена.** Та же клавиша сразу после автоисправления возвращает слово как было и запоминает его как исключение.
- **Исправление выделенного текста.** Выделили фразу, набранную не в той раскладке, нажали клавишу — фраза исправлена.
- **Таджикские буквы.** «хамчун» → «ҳамчун», «чахон» → «ҷаҳон», «точикистон» → «тоҷикистон». Слова, которые и так правильные («ки», «кор»), не трогаются. Для двусмысленных («ки» → «кӣ», «хар» → «ҳар») — клавиша ручного исправления.
- **Дописывание слов** по словарю: серый текст прямо после курсора, тем же шрифтом и размером, что и в поле, Tab — принять и сразу поставить пробел. Учитывает предыдущее слово: встроенная статистика пар слов из больших корпусов текстов («может пок…» → «покажешь», а не «пока») плюс пары, которые пишете вы сами.
- **Нейро-подсказки (модуль, по желанию).** Продолжение фразы от локальной языковой модели. Встроенный движок [llama.cpp](https://github.com/ggml-org/llama.cpp) работает с любым файлом модели GGUF — например, уже скачанным для других программ (Qalam сам найдёт их). Модель грузится в память только когда нужна и выгружается после простоя. Как вариант — подключение к [Ollama](https://ollama.com). Текст никуда не отправляется.
- **Пауза** одной клавишей или из значка в трее / строке меню.
- Учитывает язык соседних слов. Короткое первое слово исправляет задним числом.
- Не трогает ссылки, почту, код и слова с цифрами. Есть список программ-исключений: менеджеры паролей, игры и т. д.
- Работает только на вашем компьютере, ничего не отправляет в интернет.

## Горячие клавиши по умолчанию

| Действие | Windows | macOS |
|---|---|---|
| Исправить слово / отменить | Pause/Break | Shift дважды |
| Исправить выделенное | Shift + Pause | Control дважды |
| Пауза | Alt + Pause | Option дважды |

Все клавиши меняются в настройках: можно выбрать вариант из списка или записать свою комбинацию кнопкой «Записать» (Ctrl + Shift + Q, F9, CapsLock и т. д.).

## Установка

Скачайте последнюю версию на странице **Releases**.

- **Windows:** `Qalam-Setup-….exe`. Права администратора не нужны. Если Windows SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
- **macOS:** `Qalam-…-macOS-AppleSilicon.dmg` (M1–M4) или `…-Intel.dmg`. Перетащите Qalam в «Программы». При первом запуске нажмите на значок правой кнопкой → «Открыть». Затем разрешите доступ в «Системные настройки → Конфиденциальность и безопасность»: «Универсальный доступ» и «Мониторинг ввода».

Таджикская раскладка должна быть добавлена в системе. Windows: Параметры → Время и язык → Язык → добавить «Таджикский». macOS: Настройки → Клавиатура → Источники ввода.

## Как это устроено

```
src/Qalam.Core              ядро: словари, n-граммная модель, решение «в какой раскладке слово»
src/Qalam.Platform.Windows  перехват клавиатуры (WH_KEYBOARD_LL), ввод (SendInput), раскладки (ToUnicodeEx)
src/Qalam.Platform.Mac      CGEventTap, CGEventPost, Text Input Sources / UCKeyTranslate
src/Qalam.App               окно настроек и значок в трее (Avalonia)
tests/Qalam.EngineTest      проверка встроенного движка llama.cpp на крошечной модели
tests/Qalam.Sim             симуляция набора: точность и ложные срабатывания
```

**Словари:** таджикский — из «Фарҳанги тафсирии забони тоҷикӣ» (2 тома) и «Фарҳанги забони тоҷикӣ» (1969), около 86 тыс. словоформ. Русский и английский — частотные списки wordfreq.

**Сборка:** GitHub Actions собирает установщик для Windows и .dmg для macOS при каждом коммите (вкладка Actions). При теге `v*` создаётся релиз.

Локально: `dotnet run --project src/Qalam.App` (нужен .NET 8 SDK).
